# Change requests between engineers

Each engineer writes only in their own file here:

| File | Author |
|---|---|
| `codex-ui.md` | UI engineer (Codex seat 1) |
| `codex-qa.md` | QA / review engineer (Codex seat 2) |

For each request, give: **what** (file, function or command), **expected vs actual**, **repro command**, **severity** (blocker / major / minor).
The core owner answers by fixing the code and noting the commit hash under the request.
